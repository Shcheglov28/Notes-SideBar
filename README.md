# Notes Sidebar

Расширение для Firefox, предназначенное для создания и управления заметками в постоянной боковой панели (Sidebar). Позволяет сохранять контекст веб-страниц без переключения между вкладками и приложениями.

## Функциональность

- **Постоянная боковая панель:** Интерфейс не закрывается при потере фокуса или переключении вкладок.
- **Контекстные заметки:** При создании новой заметки автоматически извлекаются URL и заголовок активной вкладки.
- **Управление списком:** Сортировка по дате или ручное перетаскивание (Drag & Drop) с сохранением позиции.
- **Поиск:** Мгновенная фильтрация заметок по заголовку и содержимому (с защитой от ложных срабатываний при быстром вводе).
- **Кастомизация:** Поддержка светлой и темной темы, а также выбор акцентного цвета интерфейса.
- **Визуальная группировка:** Назначение цветовых меток для отдельных заметок.
- **Защита от потери данных:** Механизм отложенного удаления (Undo) с очередью восстановления. Данные не стираются навсегда при случайном клике.
- **Local-first:** Все данные хранятся исключительно на устройстве пользователя в `browser.storage.local`. Сбор телеметрии и передача данных на сторонние серверы отсутствуют.
- **Импорт/Экспорт:** Выгрузка и загрузка всех заметок в формате JSON для резервного копирования и переноса между устройствами.

## Установка

### Для пользователей (Production)
Расширение доступно в официальном каталоге Mozilla Add-ons:
[Установить Notes Sidebar](https://addons.mozilla.org/ru/firefox/addon/notes-sidebar/) *Ссылка будет добавлена после апрува модеров firefox-a*

### Для разработчиков (Development)
Для запуска актуальной версии из исходного кода:
1. Клонируйте репозиторий.
2. В адресной строке Firefox перейдите на `about:debugging#/runtime/this-firefox`.
3. Нажмите **Load Temporary Add-on**.
4. Выберите файл `manifest.json` в директории проекта.

## Технологический стек

- **Платформа:** WebExtensions API (Manifest V3).
- **Язык:** Vanilla JavaScript (ES6+), без использования тяжелых фреймворков (React/Vue).
- **Стилизация:** Нативный CSS. Темы реализованы через CSS-переменные (`:root`).
- **Хранилище:** `browser.storage.local`. Реализован слой абстракции для возможности миграции на IndexedDB или SQL в будущем.
- **Сторонние библиотеки:** [SortableJS](https://sortablejs.github.io/Sortable/) для реализации Drag & Drop.
