# Notes Sidebar
Расширение для Firefox, предназначенное для создания и управления заметками в постоянной боковой панели (Sidebar). Позволяет сохранять контекст веб-страниц без переключения между вкладками и приложениями.

## Функциональность

- **Постоянная боковая панель:** Интерфейс не закрывается при потере фокуса или переключении вкладок.
- **Контекстные заметки:** При создании новой заметки автоматически извлекаются URL и заголовок активной вкладки.
- **Markdown и Wiki-связи:** Поддержка базового форматирования Markdown (жирный, курсив, списки) и кликабельных связей между заметками через синтаксис `[[Название]]`.
- **Организация списка:** Сортировка по дате, ручное перетаскивание (Drag & Drop), а также закрепление важных заметок (Pin) в самом верху списка.
- **Фильтрация и Поиск:** Мгновенный поиск по тексту и фильтрация заметок по домену текущей активной вкладки.
- **Быстрое копирование:** Возможность скопировать текст заметки в буфер обмена прямо из списка.
- **Кастомизация:** Поддержка светлой и темной темы, а также выбор акцентного цвета интерфейса.

- **Защита от потери данных:** Механизм отложенного удаления (Undo) с очередью восстановления. Напоминание о создании резервной копии при накоплении базы заметок.
- **Local-first и Безопасность:** Все данные хранятся исключительно в `browser.storage.local`. HTML-рендеринг очищается через DOMPurify для предотвращения XSS-атак.
- **Импорт/Экспорт:** Выгрузка и загрузка всех заметок в формате JSON для резервного копирования.

## Установка

### Для пользователей (Production)
Расширение доступно в официальном каталоге Mozilla Add-ons:
[Установить Notes Sidebar](https://addons.mozilla.org/ru/firefox/addon/notes-sidebar/) *(Ждём апрува модеров день 3...)*

### Для разработчиков (Development)
Для запуска актуальной версии из исходного кода:
1. Клонируйте репозиторий.
2. В адресной строке Firefox перейдите на `about:debugging#/runtime/this-firefox`.
3. Нажмите **Load Temporary Add-on**.
4. Выберите файл `manifest.json` в директории проекта.

## Технологический стек

- **Платформа:** WebExtensions API (Manifest V3).
- **Язык:** Vanilla JavaScript (ES6+), без использования тяжелых фреймворков.
- **Стилизация:** Нативный CSS. Темы реализованы через CSS-переменные (`:root`).
- **Хранилище:** `browser.storage.local`.
- **Сторонние библиотеки:** 
  - [SortableJS](https://sortablejs.github.io/Sortable/) (Drag & Drop)
  - [Marked](https://marked.js.org/) (Парсинг Markdown)
  - [DOMPurify](https://github.com/cure53/DOMPurify) (Санитайзинг HTML)
